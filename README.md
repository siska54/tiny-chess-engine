# Chess Engine — make.fun tiny-chess-01

A compact Python chess engine built for the [make.fun](https://make.fun/bounty/tiny-chess-01) coding bounty.

## About

- **Size**: ~2,700 bytes (limit: 4,096 bytes)
- **Algorithm**: Alpha-Beta search, depth 3
- **Board**: 10x12 mailbox representation
- **Language**: Python 3.13, standard library only
